# ML Model Implementation

## Project Overview

This project demonstrates the implementation of a machine learning classification model using the Titanic dataset. The main objective is to predict whether a passenger survived the Titanic disaster based on different passenger details. A Logistic Regression model was used as the baseline classification model.

## Dataset

- **Dataset:** Titanic Dataset
- **Type:** Classification
- **Number of Records:** 891
- **Target Variable:** Survived

## Work Completed

The following steps were performed during this project:

- Loaded the Titanic dataset into a Jupyter Notebook.
- Performed basic exploratory data analysis (EDA) to understand the dataset.
- Checked the dataset structure, summary statistics, missing values, and duplicate records.
- Selected the relevant features for model training.
- Filled missing values and converted categorical data into numerical values.
- Split the dataset into training and testing sets using an 80:20 ratio.
- Trained a Logistic Regression model.
- Evaluated the model using Accuracy and F1-score.

## Results

The trained model produced the following results:

- **Accuracy:** 79.89%
- **F1-score:** 0.75

These results show that the Logistic Regression model performs reasonably well for predicting passenger survival and provides a good baseline for this classification task.
